# Every symbol a Release|Win32 winmm.dll exports, as "name" or "name@N".
#
# N is the __stdcall stack size from the decorated symbol. Recording it means
# this file pins the calling convention and argument size of each export, not
# just its spelling -- a thunk that got a signature wrong would still export
# the right name. What is deliberately NOT recorded is which symbol /OPT:ICF
# folded a body onto: that is a linker optimisation, not ABI, and it changes
# whenever two functions stop compiling to identical code.
#
# docs/OPENSHIM_SDK_V2.md makes GetModuleHandleA("winmm.dll") the documented
# discovery path for companion DLLs, so losing a line here is an ABI break.
# The Linux lane checks these names against src/winmm.def as text; the Windows
# lane dumpbins the freshly built DLL and diffs it against this file.
#
# Three OpenShim*-shaped entries are intentionally not in winmm.def:
# OpenShimSetWalkerCase and OpenShimWalkerTraceSummary are dllexport debug
# hooks in walker_cockpit_trace.cpp, and OpenShimSdkProvider_GetTable is how
# the bootstrap fetches the SDK provider table, and
# OpenShimBootstrap_GetApi is the single private service table the
# OpenShim plugin resolves for logging and the startup renderer result.

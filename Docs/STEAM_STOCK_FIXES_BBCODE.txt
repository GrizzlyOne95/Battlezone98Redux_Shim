[h1]Stock Battlezone 98 Redux bugs fixed by OpenShim[/h1]

Each fix below targets a confirmed defect in the stock game: one we traced to its root cause in the executable, caught in a crash dump, or measured before and after. Fixes marked [i](SP)[/i] switch themselves off in network games, so mixed OpenShim/stock lobbies behave identically. Every fix can be turned off individually in openshim.ini.

[h2]Gameplay and AI[/h2]
[list]
[*] Fixed howitzers firing at a sniper without deploying first. [i](SP)[/i]
[*] Fixed APCs refusing to drop soldiers on allied targets. [i](SP)[/i]
[*] Fixed a destroyed splinter (spraybomb) continuing to spawn payload. [i](SP)[/i]
[*] Fixed hits from comets, APC soldiers and splinter payloads not revealing the craft that fired them. [i](SP)[/i]
[*] Fixed tugs never deploying after picking up cargo. [i](SP)[/i]
[*] Fixed a dead constructor's queued build outliving it. [i](SP)[/i]
[*] Fixed a constructor getting stuck forever when another constructor finishes recycling the same target first. [i](SP)[/i]
[*] Fixed uneven motion at high frame rates caused by the engine rounding each frame step to whole milliseconds. [i](SP)[/i]
[*] Fixed the satellite view showing enemies you haven't seen. Redux had dropped Battlezone 1.5's fog check. [i](SP)[/i]
[*] Restored the 1.5 crouch when landing with the sniper rifle selected and jump held. [i](SP)[/i]
[*] Fixed your own Arc Mine firing at you on the frame you board a craft. [i](SP)[/i]
[*] Fixed units that two producers can build only being buildable from the first one the engine found.
[*] Fixed a crash from magnet mines whose ODF range is zero or invalid.
[*] Fixed ODF and TRN decimals such as 0.8 reading as 0 on non-English Windows locales.
[/list]

[h2]Multiplayer and Lua[/h2]
[list]
[*] Fixed a host crash (heap corruption) when a guest owns scavengers and a team runs an AIP.
[*] Fixed multiplayer links dropping every position update after a single retransmit. It was worst with 3 or more players.
[*] Fixed position updates being thrown away until a lost reliable packet was resent.
[*] Fixed lost reliable messages waiting for the slow retry timer because the request to resend them was discarded.
[*] Fixed Lua Send of a 128-255 byte string or table crashing every receiving player.
[*] Fixed Lua Send of map-placed objects (geysers, beacons, scenery) arriving as nil on other players.
[*] Fixed the Lua Formation(unit, leader, priority) binding. Stock registered a copy of Recycle, which rejected the leader handle.
[*] Fixed the Lua CanBuild and IsBusy checks giving wrong answers for base producers.
[*] Fixed the multiplayer map list jumping or resetting while browsing (Steam).
[*] Fixed the multiplayer vehicle list using stock assets instead of the selected mod's.
[*] Fixed the black craft in the multiplayer Create Game preview on DX11.
[*] Fixed the Create Game map layout preview overflowing its frame.
[/list]

[h2]Crashes[/h2]
[list]
[*] Fixed a first-frame crash when a pilot ODF puts weaponHard1 outside [GameObjectClass], or a script empties the selected pilot weapon slot.
[*] Fixed a crash when a saved mission loads a stale object handle.
[*] Fixed a crash and a stuck turbo sound on hover craft whose thrust and turbo sounds share one wav file.
[*] Fixed a crash on hover craft models with more than 8 throttle nacelles.
[*] Fixed a crash from a draw_multi ODF with a missing or garbage renderCount.
[*] Fixed a crash when a map or mod thumbnail BMP can't be decoded.
[*] Fixed a crash when leaving a multiplayer lobby for the main menu.
[*] Fixed a crash when a mod declares a duplicate Ogre material.
[*] Fixed the game quitting with "complete render failure" when a Lua error alert opens during a render exception.
[*] Fixed a crash on exit under DX11.
[*] Fixed a crash on exit from the lens flare cleanup running after Ogre's materials are gone.
[*] Fixed a crash after a graphics driver reset on DX11. The device and its buffers are now rebuilt.
[*] Fixed an editor crash on the second editing session.
[*] Restored legacy ODF section headers that 1.5 accepted, such as a bare [GameObject] that otherwise quits mission load.
[/list]

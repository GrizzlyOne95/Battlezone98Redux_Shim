## ---------------------------------------------------------------------------
## Negative findings (recorded deliberately)
## ---------------------------------------------------------------------------
# - Byte pattern `C1 E0 02 83 E0 3C` (shl eax,2 ; and eax,0x3C - the Mac perm-state
#   flag-byte build) does NOT occur in the Windows image. MSVC x86 allocated
#   different registers. Instruction-byte matching across the two toolchains is
#   not a usable correlation technique here.
# - The composite pattern (shl reg,0x10) + (add reg,[abs]) + (inc [abs]) used by
#   Mac SetLocal to compose the network ID does NOT occur. Only 17 distinct
#   `inc dword ptr [abs32]` sites exist in the whole Windows .text; MSVC emitted
#   load/increment/store instead. Not a usable anchor.
# - DistributedObject::codes[] lives in __bss on Mac (0x100A95EC0) and is built at
#   runtime, so it is NOT available as a static byte-array anchor on either side.
# - No Windows correlation was attempted for SetLocal/SetRemote/UpdatePermState in
#   this pass: they reference no string literals, and no other evidence class was
#   strong enough. Recorded as open work rather than guessed.

## Wire format - proven identical across ABIs
## ---------------------------------------------------------------------------
# Mac x86_64 writer  : DistributedObject::UpdatePermState @ 0x10009FCF0
#                      writes into DistributedObject::packet_buffer @ 0x102DF3650
# Win x86 reader     : DistributedObject::Create @ 0x004B9350
#
#   offset  width  field                          Mac evidence        Win evidence
#   +0x00   u8     packet length                  (length checks)     cmp 0x15 / 0x1C
#   +0x01   u8     flags: bit7 = is-local-user    mov [pb+1],al       mov al,[edx+1]
#                         bits2..5 = class<<2
#   +0x02   u32    object network ID              mov [pb+2],eax      mov ecx,[eax+2]
#   +0x06   14B    reduced transform matrix       NetUtil_ReduceMatrix read +0,+4,+8,+0xC
#   +0x14   u8     compact class code | 0x80      mov [pb+0x14],bl    movzx [edx+0x14]
#
# Compact form total 0x15 (21) bytes; non-compact form substitutes the 8-byte ODF
# class name for the 1-byte code, giving the 0x1C (28) minimum the Windows reader
# enforces. 0x15 - 1 + 8 = 0x1C, self-consistent.
# No field is pointer-width. No field changed between the 32-bit and 64-bit build.

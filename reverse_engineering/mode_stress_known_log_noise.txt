# Known benign log lines for Run-BZRModeStress.ps1 (Docs/RELEASE_QUALIFICATION.md,
# "Mode-transition stress (unattended)").
#
# A line the harness flags (error / exception / fail / assert / warning patterns,
# OpenShim [WARN] and [ERROR]) fails its step as FAIL-LOG unless a rule here
# matches it. Matches are still counted and printed under "Allowlisted log
# lines", so nothing is hidden. Keep every rule narrow and say WHY it is benign;
# never add a rule just to turn a run green. Re-score a run after editing this
# file with:  Run-BZRModeStress.ps1 -AnalyzeOnly <report dir>
#
# Format: <log glob> :: <regex>
#   <log glob>  matches the report's log label: the path under the game root
#               with separators turned into "_" (logs_BZLogger.txt,
#               logs_openshim.log, logs_BZOgreLogfile.log, logs_exu.log,
#               logs_openshim_crash.log, BZLogger.txt, ...). "*" = any log.
#   <regex>     .NET regex, case-insensitive, matched anywhere in the line.
